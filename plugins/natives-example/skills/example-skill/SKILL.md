# Natives Example Skill

This is an example skill that demonstrates the skill system.

## Overview

Skills are loaded from `plugins/<name>/skills/<skill-name>/SKILL.md`.
They use YAML frontmatter with `name`, `description`, `version`, and `license` fields.

## Usage

When you need to perform tasks related to this skill, follow these guidelines:

1. Understand the context and requirements
2. Use the appropriate tools and capabilities
3. Follow best practices and conventions
