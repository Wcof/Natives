三步加载扩展

Load the extension in three steps

先做第 0 步：双击"应用程序"里的 Natives——它会自动打开扩展管理页、在"下载"文件夹创建并定位扩展快捷方式、并把目录路径复制到剪贴板。本页如果是双击 Natives 打开的，第 0 步已完成。Step 0 first: double-click Natives in Applications — it opens the extensions page, creates and reveals the extension shortcut in Downloads, and copies the folder path. If this page was opened by double-clicking Natives, step 0 is already done.
  1. （可选）打开扩展管理页：(Optional) Open the extensions page:chrome://extensions
  2. 打开右上角"开发者模式"。Turn on "Developer mode" (top right).
  3. 点击"加载已解压的扩展程序"，选择"下载"文件夹里的 Natives-Extension（指向真实目录的快捷方式；选目录，不是 ZIP）。Click "Load unpacked" and select Natives-Extension in your Downloads folder (a shortcut to the real folder; a folder, not a ZIP).

之后怎么打开

How to open Natives afterwards

以后从"应用程序"双击 Natives：扩展已就绪时直接进入产品。基金在应用中心点击打开，首次只做数据初始化——没有"安装基金"。Double-click Natives in Applications; once the extension is ready you go straight into the product. Open Fund from the App Center — first use only initializes data, there is no "install fund".

常见问题

Common questions

没有 Chrome？No Chrome? 从 google.com/chrome 获取官方 Chrome 后重试。Install official Chrome from google.com/chrome and retry.

页面打不开 / 扩展被停用？Page won't open / extension disabled? 在 chrome://extensions 里重新开启；重复加载同一目录是安全的。Re-enable it in chrome://extensions; loading the same folder again is safe.

升级/重装后？After an upgrade/reinstall? 目录不变，通常无需重载；版本不对时在 chrome://extensions 点击刷新。The folder stays the same; usually no reload is needed — hit the reload icon in chrome://extensions if versions differ.

安全与隐私

Security and privacy

本页来自本次安装包，不请求网络。Natives 不会静默修改 Chrome 配置；"产品配置"只在你在扩展前台明确点击后执行；基金数据保存在你的用户数据目录。This page ships inside the installer and makes no network requests. Natives never silently modifies your Chrome profile; product configuration runs only after you explicitly click it; Fund data stays in your user data directory.
