常见问题

Common questions

没有 Chrome？No Chrome? 从 google.com/chrome 获取官方 Chrome 后重试。Install official Chrome from google.com/chrome and retry.

扩展被停用？Extension disabled? 在 chrome://extensions 里重新开启即可。Re-enable it in chrome://extensions.

升级/重装后？After an upgrade/reinstall? 目录不变；若版本不一致，必须在 chrome://extensions 点击刷新图标重载扩展。The folder stays the same; if versions differ, reload via the refresh icon in chrome://extensions.

点击按钮没反应？Button does nothing? 从"应用程序"双击一次 Natives 后再试；或在 Chrome 地址栏手动输入 chrome://extensions。Double-click Natives in Applications once, or type chrome://extensions in Chrome's address bar.

安全与隐私

Security and privacy

本页来自本次安装包，不请求网络。Natives 不会静默修改 Chrome 配置；"产品配置"只在你在扩展前台明确点击后执行；基金数据保存在你的用户数据目录。This page ships inside the installer and makes no network requests. Natives never silently modifies your Chrome profile; product configuration runs only after you explicitly click it; Fund data stays in your user data directory.
