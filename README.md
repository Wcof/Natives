# Natives

> **Natives 本地工作台** · 单一完整产品 · v0.1.0

Natives 是一个完整产品：Manifest V3 扩展提供界面，Rust/Go Native Hosts 提供本地能力，空间、文件、AI 和投资（含基金记账）作为内置模块随同一安装包交付。正式分发尚未完成，平台签名/公证和 Windows 实机门禁仍在外部流程中。

当前源码中，空间提供五种投资卡片与投资概览模板；投资模块首页展示管理资产／已估值资产、股票／基金／线下投资／全资产四类收益和整卡背景目标水位与固定刻度，资产分布与组合设置并排对照，资讯与原地 AI 决策等高展示，资讯按来源／标题／摘要分层阅读，推理过程显示连接／核对证据／生成阶段并可取消，随后显示四类收益；真实保存的估值历史、市场参考及额外研究按需展开。目标与概览取同一个账本快照；期间收益剔除外部净投入，证券浮盈与已实现收益分别展示，缺价、未知成本及历史不足时明确显示不可计算。已有证券持仓即使缺估值也展示记录数量与已知成本，缺币种可从首页确认，保留原有份额、成本和净值记录。财务分配可从独立应用／应用中心的「应用设置」或空间左下角「财务设置」进入，三种入口共用同一配置；其中 Model 按钮打开可信 Extension 的模型设置，关闭后返回模块触发按钮。持仓提供股票／场内基金／场外基金分类、账户管理、期初、买卖、转账户、历史更正和恢复；移除了持仓推荐标签，独立自选仍保留。持仓行内「更多」以浮层分组展示记账、查看分析与其他操作，一次展开一条；外部点击或 Esc 收起，取消买卖表单返回对应行。基金份额、价格、NAV 和平均成本展示最多 4 位小数，股票数量保留整数股限制，人民币金额按分结算。实物黄金、定期存款、银行理财和其他线下投资具有估值与退出到账记录。AI 经用户预览证据后使用 Model Host 的全局默认供应商与模型；四类分析报告可留存、比较和反馈。资讯合并公共财经与真实持仓／自选相关内容，来源错误和覆盖范围明确展示。功能的本地验证与尚待实际环境验收的范围见 [`ROADMAP.md`](ROADMAP.md)。

基金持仓详情分为基础信息、季度关联持仓、净值业绩与个人收益；净值和个人收益各有单日、7 天、1 月、3 月、6 月、1 年范围。季度按最近两期公开披露比较占比，前期未披露的值保留未知；个人历史按登记后的实际份额、确认交易和费用计算，登记前不补记录。股票详情先展示账户绑定的四卡持仓摘要，再切换概览、分页记录、资讯或公开趋势研究；基金详情可快捷切换真实持仓。首页资讯可原地分析、保存报告和记录决定；历史回看当时材料，不重复推理或生成交易。

资讯页默认查看全部已采集内容，首次获取覆盖公共财经、现有持仓与自选。公共财经使用东方财富国内经济、国际经济、证券聚焦和产业经济栏目，无持仓也可采集；「财经要闻」单独筛选公共内容，不冒充私人资产关联。默认排序在同一天优先财经和重要公告，也可切换最新发布。页面采用分类、时间、标题、摘要、来源和操作分层的阅读列表，搜索常显，高级筛选按需展开。打开时复用已保存数据；启用来源未采集或最近尝试超过 15 分钟时自动发起一次有界采集，也可手动刷新、取消或继续下一批。采集结果及错误在当前页显示，失败保留已加载文章；隐藏模式及已停用来源不自动采集，离开／隐藏页面会取消任务。来源覆盖仍以实际适配能力为准，不保证所有证券每日都有新增资讯。

首页、持仓记账、线下资产、自选、趋势分析、资讯和决策历史提供模块内导航，AI 入口定位首页内联区域；交易流水、市场发现、批量导入和公募净值收进工具菜单。持仓按逐账户的一项持仓一张卡片展示市值、当日／昨日与持有收益；本周、本月、本年及累计收益可展开查看，各项同时显示金额与收益率；当日／昨日标明真实价格日期，持有收益标明连续持有天数。期间收益核对历史数量、买卖与费用，百分比采用区间投入基数，缺基线明确提示；持仓占比可展开。行内「编辑」选择期初登记或原始交易，修改数量／总成本或更正数量／价格，沿版本与历史审计重新汇总；转账户记录保持成对处理，待确认交易先确认。线下资产逐项用卡片展示估值、日期、保管位置和维护动作，提供页内新增、当前页估值摘要与失败重试，部分退出与归档状态明确区分。流水列表优先展示最近 200 条中的筛选结果，录入按需展开，股票整数股与基金四位精度、场外待确认状态分别校验；交易金额与投资收益保持区分。切页取消列表读取，刷新失败保留同一筛选下已加载的数据，隐私切换直接重绘缓存。

机会投影使用已收盘行情缓存或已保存 NAV，按证券合并跨账户记录；排序评分、风险缺口和持仓行动分开，未知历史不补 0 分。股基、市场、来源池、持仓状态、策略与评分筛选采用原生表单，隐藏模式不展示候选身份。可显式刷新持仓／自选公开历史，每批最多 10 个、池最多 100 个；提供进度、下一批和取消，离开页面停止任务。股票复用现有日 K，基金回补最多 250 条公开 NAV；部分失败保留成功项并明确说明，行情参考不替代持仓账本估值。首页生成及刷新自动留存完整候选批次，同日相同事实不重复生成样本；也可显式保存，分页查看历史评分／行动／数据日期，提交有用／无用反馈及理由。修改保留版本历史，历史弹窗每页 20 个版本；统计仅计每个候选的最新反馈，不把有用率当投资胜率。

首页可按实际覆盖日期比较组合收益与所选人民币价格指数，并显示两条曲线；财务设置提供上证、沪深 300、中证 500、创业板及科创 50 基准选择。不含指数分红，不填休市报价，资金或估值未核对时保留不可计算。详情报价刷新间隔可设为 3、10、30 或 60 秒；页面后台、离开或关闭时取消自有任务，恢复时重读当前快照。

财务设置还提供显示／行情外链／来源优先级、策略／规则、九种通知渠道、跨午夜静默与有界重试、配置模板选择导入／导出、正文缓存清理和脱敏诊断。渠道凭据及模块代理密码由可信 Extension 表单写入 OS Keychain，模块 iframe 不接收明文。行情／资讯／通知默认直连，可显式验证后启用公网 HTTPS 代理；AI 网络仍由 Model Host 控制。事件、报告和候选外部通知逐次预览目的地与最小摘要，再确认发送；配置渠道不自动授权外发。模板上限 200 KiB，不包含凭据或账本交易；导出提供可选择复制的 JSON。

新保存的估值记录包含证券数量与市值明细，首页可据此核对期间价格贡献、交易费用及现金收入／费用，其他贡献单列并与净收益对账。旧快照缺明细或数量变化不能由流水解释时，归因显示需核对。

场外基金优先使用公开已公布净值及日涨幅；可见页面在开市期间按配置刷新，工作日 15:05～23:00 有待公布净值时每 60 秒检查，其他闭市时间保留 30 分钟间隔。尚未公布当日净值的人民币基金，可按最近季度披露的境内股票权重与同日行情展示「今日收益参考」、参考净值及覆盖率；未覆盖部分假定不变，交易、费用等不包含在此估算中。参考值不写入真实净值、确认收益或目标水位，正式净值公布后优先展示确认数据；没有有效覆盖时明确保留未知。持仓首次读取被浏览器切页打断后恢复一次读取，已加载的持仓不因短暂切页重新初始化。

持仓页的账户管理与汇总常驻显示，首页摘要「今日收益」与证券持仓当天收益共用口径，支持负值和明确标注的基金估算；线下应收与全资产净收益仍独立展示。基金卡片和详情可显示天天基金公开主题，未提供主题时展示公开跟踪指数，附来源及采集时间；热门推荐不当作主题归属。资料单独加载、缓存 24 小时，可见视图每次最多 20 只基金，失败可重试，隐藏／离开取消；没有明确公开分类时保持未知。

## 当前文件产品

```text
Chrome/Chromium
  ├─ newtab.html  → 轻量工作台入口
  └─ files.html   → 直接 connectNative
                    → crates/native-file-host
                      → crates/file-manager-core
                        → 本地文件系统
```

`newtab.html` 不读取文件系统、不创建 Native Port。Service Worker 只处理工具栏入口；不持有 Native Port、不轮询、不保活。关闭文件页后 Chrome 关闭 stdio，Host 在 EOF 时清理 watcher/后台任务并退出。

## 一键启动（源码开发）

产品安装版本身就是单击启动：打开 `Natives Local.app` 后选择「独立网页」或「Chrome 扩展」。源码开发不想分别起 Host 和 Web，可用：

```sh
npm start
```

默认就是**独立 Web**：构建 Host、启动共享 Core 服务（`127.0.0.1:8771`），并直接打开 `http://127.0.0.1:8771/space.html`。不会打开 Chrome 扩展页。

需要同时打开扩展和 Web 两个入口时：

```sh
npm run app
```

首次使用扩展仍需在 `chrome://extensions` 手动加载一次 `dist/dev-extension`（Chrome 不允许脚本静默安装未上架扩展）。

只启动扩展开发宿主、不启 Web、不开浏览器：

```sh
npm run dev
```

服务只监听 `127.0.0.1`，不会监听 `192.168.x.x` 或 `0.0.0.0`；文件、数据库、Keychain 和本机 AI 能力不能暴露到局域网。`Ctrl+C` 会同时停止本会话的 dev Host 和 Web 服务。

若出现 `Specified native messaging host not found`，先看 `chrome://extensions` 里的 Natives ID 是否为 `npm start` 打印的 Expected extension ID；不一致时移除旧扩展、重新加载 `dist/dev-extension`，完全退出并重开 Chrome。不要加载源码目录 `extension/` 代替开发构建，它没有固定 key，ID 会不同。

开发注册会同时写入 Chrome、Chrome for Testing、Chromium、Brave 和 Edge 的 NativeMessagingHosts，并允许开发 ID 与本地候选 ID。可用以下命令核对每个浏览器的清单、Host 路径和 allowed_origins：

```sh
npm run hosts:doctor
```

只启动扩展开发宿主（不启 Web、不开浏览器）：

```sh
npm run dev
```

只启动 Web 服务：

```sh
npm run web:dev
```

## 开发安装与启动

`npm run dev` 是扩展开发入口：它会先停止本项目已有的 Debug/Release Host，再构建 Debug Host、生成/更新 `dist/dev-extension` 并持久注册；Chrome 在扩展发起 Native Messaging 连接时按需启动新 Host，启动前会核验进程路径和启动时间，先停止连接进程／顶栏，再停止共享 worker；未释放或新出现的占用仍阻止构建。其他项目及正式安装目录的进程不受影响。按下 `Ctrl+C` 只清理本次命令登记的子进程。该命令不会启动浏览器。

```sh
npm run dev
```

首次运行只需要 Rust 工具链；扩展目录始终是 `dist/dev-extension`。在 Chrome 中手动加载或重新加载该目录后，页面会使用已注册的 Native Host。

手动流程只用于开发和排错，不代表正式安装：

```sh
npm install
rtk env -u CARGO_TARGET_DIR cargo build -p native-file-host

# 在 chrome://extensions 启用开发者模式，加载 extension/，复制扩展 ID
rtk node extension/install-native-host.mjs \
  --extension-id <chrome-extension-id> \
  --host-path "$(pwd)/target/debug/native-file-host"

# 打开普通 Chrome/Chromium 的 Natives 页面；进入 files.html 后 Host 按需启动
rtk node extension/launch-natives.mjs
```

重注册时重复执行安装命令；移除开发 Host（不删除扩展）：

```sh
rtk node extension/install-native-host.mjs --uninstall
```

完整排错与平台注册位置见 [`extension/README.md`](extension/README.md)。日常不需要手动启动或关闭本地服务。

本机 Web 开发使用 `npm run web:dev`，它构建模块 UI 与 Host、密封开发产品源，然后以前台服务模式监听开发端口 `127.0.0.1:8771`。另一个终端运行 `npm run web:open` 可通过一次性会话在 Chrome 打开网页；手输地址时用 `npm run web:pair` 获取短期配对码。关闭所有入口后服务按租约和空闲宽限期退出，前台也可按 `Ctrl+C` 关闭。不会安装系统服务或开启登录自启。

macOS Launcher 提供「独立网页／Chrome 扩展」选择，可记住入口偏好；按住 Option 启动可重新选择。此偏好仅属于 Launcher，业务配置和数据库仍由原领域 owner 管理。双入口完整验收的当前缺口见 ROADMAP，不以能打开首页作为整版验收通过。

## 构建与检查

```sh
# Release Host、扩展门禁与文件性能检查
npm run extension:release

# 扩展与 Native Host 检查
npm run extension:check
npm run perf:check
```

Native Messaging 支持目录/搜索分页与取消、文件预览和写入、复制/移动/重命名、废纸篓、打开/定位及目录变更通知。路径规范化、敏感目录防护和操作白名单由 Rust Host 负责；Renderer 不直接访问任意本地路径、SQLite、进程或 Secret。

## 正式安装状态

正式版本由 macOS/Windows 完整产品安装器提供固定扩展、Native Hosts 和全部内置模块；首次运行按 Chrome 要求加载随包扩展目录。当前状态：

- 扩展体积估算：310,580 bytes（预算 368,640）；`native-file-host` Release：1,913,472 bytes；实测空闲 RSS：8,288 KB；EOF 后退出：9 ms。
- 10,000 项目录查询 5 样本 p95：46.73 ms（预算 50 ms）；Model Host 首次快照：702 ms、空闲 RSS：66,096 KB、空闲 CPU：0%。
- Chrome for Testing 148 E2E：newtab 成功，files 返回真实 roots 8 个、主目录 entries 24 个，console/pageerror 为空；关闭文件页后 Host 29.45 ms 退出且无残留。
- Windows 本地候选包脚本已就绪，真实 Windows 安装/升级/卸载生命周期仍待实机验证。
- 平台签名/公证、正式下载回测、跨平台生命周期 E2E 和卸载残留检查：仍是发布阻塞，不是代码闭环阻塞。

因此当前文档和脚本描述的是开发/验证流程，不宣称正式发布完成。
