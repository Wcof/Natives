第 2 章 · 模型知道什么

Prompt 不是一段文字，而是一组有顺序的来源

Native 会在调用模型前，把内置指令、Agent Profile、项目规则、Skill 目录和 Harness Prompt Block 依次装配。每一层都有自己的拥有者和编辑方式。

01

Native 放入基础行为指令

告诉 Agent 如何工作、如何使用工具，以及必须遵守的系统边界。这是 Native 自己拥有的 Prompt。

Native 内置指令 · 1,280 tokens可版本化替换
为什么需要它？

没有基础指令，模型只知道用户问题，不知道 Natives 的运行方式。

02

加入当前 Agent 的角色

如果会话选择了专家或专家团，这一层描述它的职责、工作风格和团队协作方式。

全栈工程师 · 能力库Team roster · 自动生成
谁可以修改？

它由能力库拥有；在这里可以查看，但需要回到能力库编辑。

03

读取项目规则和 Skill 目录

AGENTS.md 约束当前项目；Skill 目录只告诉模型有哪些专业流程可按需加载，并不会把所有 Skill 正文塞进 Prompt。

AGENTS.md · 项目文件3 个 Skill 摘要skill Tool · 模型可调用
Skill 装在哪里？

摘要进入 Prompt；正文通过 skill Tool 按需读取。只有 Skill 真声明了 Hook，才会挂到 Hook 点。
