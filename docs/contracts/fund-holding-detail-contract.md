# Fund 私人持仓详情与资讯决定补充契约

## 首页资产配置合并卡片

资产分布与组合设置合为一张“资产配置”卡片：共享标题、分类／目标编辑入口和已归类金额／目标合计／待归类摘要；宽屏左右对照实际分类树与目标／实际／偏差，窄屏上下排列。正文保持有界滚动、键盘可达，刷新保留分类展开、滚动及焦点。样式参考用户确认的合并 Demo，生产页面不使用 Demo 数据或脚本。

数据仍由 Fund `groupAllocation` 与现有 group-plan writer 唯一持有，不改变 schema、估值、资产去重或目标保存契约。金额沿用精确整数，未知估值不作零或完整总额；资产子项比例沿用分类内占比。三态隐私同时覆盖摘要、分类树、目标偏差和图形。中英文与 Archive／Volt 使用相同结构和现有语义 tokens。

目标对照表中的条形填色统一表示当前实际占比，以 100% 为整条长度，空白表示剩余占比；目标与偏差由相应数值列展示，不使用第二根细线或目标填色。未知实际占比不画条，真实零占比保留空条；hidden 模式移除图形。首页滚动正文在滚动条内侧至少留 12 px，外层滚动区保留稳定槽位，金额和偏差不贴右边。

## 首页资产走势与市场合并（2026-10-21）

2026-10-22 展示修订：“收益与表现”四类摘要与资产走势／更详细收益合为一张常驻卡片，位于“资产配置”上方。共享一个标题与外层边框，顶部为股票／基金／线下投资／全资产摘要，下方保留市场、累计与已投资金额、收益区间、分类走势、基准和归因。分类选择及其下方资产估值展示保留，不删除。

首页移除“财务分配与核对工具”和“机会与投资依据”两个区块；“与我相关的市场”改名为“市场”，并入当前“收益与表现”卡片。分类名称与当前估值来自同一快照的 `groupAllocation`。默认看总资产；主图按 Demo 口径把总资产与所选分类都归一化为区间首个可绘制点的 0%，总资产常显、所选分类叠加，两者共用同一百分比刻度，不叠加绝对金额。分类标签显示该序列的区间变化（末点／首点−1），只表示该分类自身走势，不代表组合整体收益；分类没有至少两个有效点时不画线，也不顶替总资产金额。

历史分类值只读取对应记录保存的 `groups`，当前零值保留为零，未知金额不回退总资产，历史范围不回填当前金额。`value_snapshots` 仍是手动核对估值与收益基线的唯一来源，原表单及 `breakdown_json.groupValues` 保持。观察走势不等于收益，不参与 TWR、基准、归因或资金核对。

2026-10-22 日内走势补全：Fund schema v29 新增同库 `valuation_observations` 派生观察表，Fund 是唯一 writer。首页现有可见刷新显式调用 `POST /api/home/valuation/observe`（仅接受空对象；金额、时间、分类及 revision 由服务端快照生成），`GET /api/home/snapshot` 与空间卡片仍只读。写入事务核对快照 revision；观察写入不推进账本 revision，但保留 writer／迁移恢复标记。每个北京时间分钟最多保留该分钟最新一次真实观察，多窗口同分钟幂等，时钟回拨拒绝覆盖较新观察。历史日压缩为每日最后一次观察，保留最近 400 天；手动核对快照不清理。

“今天”按真实 `observedAt` 排序绘图，同日手动快照仅在 `created_at` 确属估值当天时进入日内序列。最多投影 200 个真实样本，点集超过 96 KiB 时进一步减少样本，保留首尾与缺口；缺值或超过 5 分钟无观察的时段断线，不补隐藏期间记录。有两个有效观察且金额相同则显示平线，只有一个时显示单点和自动积累提示。日内分类读取每个观察自身分类值，不把历史观察替换成当前分类金额。月／年／跟踪以来按日投影；若所选区间实际仅今天有记录，则自动展示今日时间点，无需额外切换。新分类没有跨日历史时，使用同一响应的有界 `todayPoints` 展示真实日内观察，不改变收益区间或把总资产历史当作分类历史。手动快照优先，无手动快照的日期可以使用当日最后观察并明确参考语义，日期缺口断开。现有收益区间、隐私、取消、隐藏与进程回收 owner 不变，不新增轮询或常驻任务。

市场当前只接入 A 股、港股、美股真实行情源。日股、韩股、欧股、亚太尚无已核实的行情源，不在生产页面伪造分类或点位；需要先扩展后端固定来源与契约后再加入。市场切换只重绘已返回的真实报价，失败保留最后成功数据并显示来源／时间。中英文、Archive／Volt、窄窗与键盘焦点沿用现有语义组件。

### 已登记基金的历史估值回放

资产走势不能只读取手动核对快照和启用后的观察记录。月／年／跟踪以来还需从已登记期初、已确认交易和校准恢复当日份额，乘以本地已确认 NAV，只读投影最近最多 400 天；登记前不补零，未知成本不阻止市值计算。沿用最新已发布净值估值规则，保留实际净值日期，超过 7 天或未知币种保持缺口。总资产只有全部历史资产均可覆盖时才给完整值，不能将基金小计冒充含现金／线下资产的总资产。

参考回放使用当前分类绑定查看历史份额价值，明确标记“按当前分类回看”，不冒充当年的分类记录；含无法回放资产的分类保持未知。已保存的估值／观察优先，不改写旧快照。回放限 200 个账户／标的身份和合计 10000 条账本记录，超界保留原有已保存估值并提示；历史点集预算 96 KiB，超出时保留最近的连续日期段并标记截断。回放不产生观察记录、收益基线或 TWR，不新增 schema、网络请求或后台任务；空、缺价、非人民币、超界与断线状态须可见。验证覆盖无估值快照但有多日持仓／NAV、买卖与校准、未知成本、缺价、分类、混合资产、只读性和真实 Chrome。

## 私人收益历史

`GET /api/holding/income-history` 接受正整数 `accountId`、`fundId`、北京时间日期 `from`、`to`，区间最多 370 天，结束日不晚于当前北京时间。可传 `expectedRevision`；版本变化返回 409，不混合新账本与旧持仓摘要。不存在或已归档账户／标的返回 404。

响应包含 `dataRevision`、`from`、`to`、`rows`、`status`、`missingCount`。每行 `date`、`amount`（元的精确十进制字符串或 null）、`rateBps`、`baselineDate`、`reason`；金额和比率沿用 `IncomeBook` 的历史份额、确认交易、费用与资金流规则，不使用 UI 当前份额。未持有日期不补零；价格／账本覆盖不足明确缺口。

用户于 2026-10-12 明确口径：只显示登记持有后有依据的个人收益，登记之前为空，不回补假记录。真实券商／银行到账没有接入时显示空状态，不阻塞其余整改。AI 沿用 ADR-0037／ADR-0044 的统一 Extension broker → Model Host 直连调用与现有供应商配置，不增加模块直连或模块凭据副本。

## 季度披露比较

优先获取天天基金档案最近两期真实披露，以证券身份对齐净值占比并计算百分点差，不将供应商单个变化字段直接当作比较结果。响应注明本期、上期报告截止日、来源与覆盖范围；上期未出现在披露集合中只标记未披露，不擅自视为零持仓或新建仓。跨年时查询上一年。移动端当前披露可作来源降级及板块补充；不能获取前期时不伪造比较值。

公开价格和私人账本分开：场外优先已保存 NAV，覆盖不足时锁外补充最多 400 条公开历史且本地值优先；场内仅使用未复权价格历史，复用现有市场缓存，锁外取得来源后再校验账本版本。查询不保存估值或产生交易。币种未核实或不支持时明确 unavailable。校准按实际锚点恢复后续数量；跨校准当天不能可靠归因时返回明确原因，不能将校准差额当收益。无法归属到本标的的账户现金事件不擅自分摊。

占比变化只表示披露权重的百分点差，不能推断为基金经理实际增持或减持。档案适配器不填充交易变化类型；UI 明确每类最多 100 项与未披露部分未知。

Frontend `fund-detail` 拥有选中账户／标的、范围、取消与代际；图表 renderer 拥有图表及异步初始化代际。离页、隐藏、隐私、语言／主题改变遵守现有 Surface 事件，迟到结果不能重建离页图表或覆盖新身份。

## 资讯决定（用户已授权 v28 增量实施）

### 资讯正文与详情

`POST /api/information/content` 继续只接受已保存的正整数 `id`、`expectedVersion` 与 `requestId`，由现有 Surface 资讯任务管理取消与落库。股票／基金公告均从已保存 `AN` 公告身份构造固定 HTTPS 正文端点，按上游 `page_size` 顺序读取；总时限 20 秒、单响应 2 MiB、正文存储 64 KiB，超过容量或分页上限必须标 `truncated`，后续页失败不能将第一页冒充 `full`。财经／股票新闻从已保存的数字文章身份构造东方财富固定 HTTPS 文章地址，只读取正文容器并转换为纯文本；不接受页面传 URL、不执行脚本、不跟随重定向、不绕过访问限制。无正文／解析失败明确区分，不能以摘要或导航冒充全文。

用户打开详情先显示弹窗与本地摘要，再按需取得尚未抓取的受支持正文；24 小时缓存继续复用，过期由用户明确刷新。读取或抓取失败在弹窗内提供可见错误与重试，保留已有摘要／正文。关闭、切换条目、隐私隐藏及页面卸载释放该详情请求，迟到结果不得重建弹窗；中英文、主题、窄窗与键盘操作一起验证。详情投影给出 `contentSupported` 与条目级原文链接，基金公告不能只打开公告列表页。来源禁用、版本冲突、缓存清理及取消在提交时重新核验；不改 schema、AI 证据身份或阅读／收藏状态。

现有 `decision_records` 的 `event_id` 是非空 `watch_events` 外键，动作仅允许 observe／defer／done；因此禁止提交 eventId=0、中文动作或伪造规则事件来记录资讯决定。

v28 仅新增 `information_decisions` 表，不重建旧表：真实 `information_id` 与已保存 `report_id` 外键，动作、用户理由、唯一 requestId、创建时间。报告内已有证据快照、数据版本、模型和资讯内容版本，决定以报告为不可变依据。迁移重复执行、v27 保留数据、外键、失败回滚和重试幂等须验证；只在隔离库运行。

写操作验证 report.task=news_impact、证据确含该资讯、资讯内容版本和报告未删除。用户通过现有 dialog 选择 observe／defer／done 并输入理由；保存操作不会改变事件状态、账户资金或生成交易。历史列表返回两类记录的明确 sourceKind，原规则事件路径保持兼容。

用户于本会话明确授权 v28 新增表与隔离库验证。不得将报告保存或决定记录视为成交；不得在修复验收中操作真实用户库。

决定历史的「查看报告与材料」通过现有 `GET /api/analysis/reports?id=<正整数>` 精确定位已保存报告。默认分页列表保持原响应范围；指定 ID 时追加该报告的不可变 evidence 快照，不依赖当前资讯正文或最新行情重建。非法 ID 返回 400；不存在／默认未包含归档报告时返回空列表。历史查看可显式传 `includeDeleted=1` 并标注归档状态，不触发推理或新交易。报告查看沿用金额隐私限制，隐私切换关闭私人模态。

### 当日基金更新与穿透估算

进程内行情缓存保存标的身份、价格与上游时间，不保存账本数量作为后续估值权威。偏好、规则及资讯等写入推进 revision 后，同一 Store 的已有标的价格仍可复用；消费时重新读取当前数量、NAV 和资产，按当前 revision 重建估值批次。新增标的缺价仍为未知，旧时间必须保留，不能将缓存价格伪装成刚取得的行情。不同 Store 的行情不得串用。

正式净值仍由既有 NAV 同步进入 `fund_nav`，持仓／首页优先使用已发布的今日确认值。未确认今日净值时，在既有 API 中另提供 `estimate`／`income.estimatedDay`：用最新公开季度股票持仓权重乘以同日场内报价涨幅，计算已披露仓位的贡献及当前份额的参考金额。未披露或缺同日报价的仓位不外推，估算净值仅是“其余仓位不变”的参考情景；必须展示模型、披露日期、行情时间、覆盖率及不完整状态，不得称为真实净值／真实当日收益。

估算不写入 NAV、收益历史、核对快照、现金、成本或交易确认。场内股票／ETF 继续消费真实报价；场外估算在模块锁外获取资料与行情，使用现有有界缓存，版本变化后重新取账本数量。首页与持仓共用同一计算口径，基金详情和卡片可展示当日估算金额／涨幅及参考净值，确认数据发布后优先显示确认值。

共享前端调度继续按配置处理开市行情；净值发布窗口内有未更新基金时，休市检查缩短至 60 秒，其他休市仍为 30 分钟。NAV 读取尝试至少间隔 30 秒并去重，已更新今日净值后停止重复同步；隐藏／离开取消 owner 任务，不新增常驻服务或独立轮询。

本轮仅调整模块 UI 投影，现有 Host／账本／公开行情／统一推理代理仍为 owner，不新增数据表。

- 资讯、决策历史提供独立模块内浏览视图；首页资讯的 AI 决策继续在首页内联更新，不恢复旧独立 AI 跳转。
- 资讯页默认展示全部已采集资讯，all 采集覆盖公共财经、持仓与自选；首页默认仍为持仓相关。公共财经采用东方财富国内经济、国际经济、证券聚焦、产业经济栏目公开列表，固定来源 `em_finance`，无持仓也采集；market 只采集／展示该来源，不发送私人身份。无明确证券身份的财经资讯不建立私人关联。沿用现有来源状态、个人收藏、归档、幂等存储及任务 owner，不新增 schema；单次最多 30 条公共财经、整体 200 条、20 秒，公共财经先采集以免被持仓队列挤掉。栏目合并时按上游文章 ID 去重，重复采集保留个人收藏与归档状态。默认排序在同一天按政策／经济数据主题、市场主题、其他财经与一般公告排列，再按发布时间；公共财经不凭“重磅／独家”等标题措辞提权，这只是明确的主题规则，不是 AI 判断或个人适配评分。标题、摘要、来源和真实时间分层呈现，范围／检索常显，高级筛选折叠，匹配静态原型的资讯阅读布局。进入资讯页先读已保存内容及来源状态；在金额／比例展示模式下，启用来源尚未采集或最近尝试已超过 15 分钟时，发起一次有界采集。相同会话失败尝试同样节流，显式刷新不受此限制。来源禁用及隐藏模式不自动采集；离开／隐藏取消页面拥有的任务。页内提供刷新、取消、下一批及真实结果／失败提示，完成后同时更新资讯页与首页投影，复用现有 refresh/status/cancel API，不生成 AI 或交易。
- 线下资产采用卡片，金额使用整数 minor 的精确格式化；分页汇总明确为本页范围，完整管理资产仍由首页快照提供。
- 股票私有详情采用顶部四卡摘要及概览／记录／资讯／研究栏目；公开图表与绘图能力保留在研究栏目。记录按账户和基金身份查询，保持分页、语言切换时的页码及取消／隐私防护。
- 基金详情保留基础信息常驻及三个图表栏目，增加真实持仓选择器、区间摘要，季度表按名称／最新涨幅／占比／较上期排列。
- 市场发现卡片消费真实板块行情，完整板块表可展开；不会把 Demo 候选或固定技术分数写入生产。

## 2026-10-19 · 趋势分时消费契约

`/api/trends/minute` 与 `/api/market/minute` 共用行情 owner，返回 `symbol/date/source/preClose/points`。来源由后端实际固定请求的 `web.ifzq.gtimg.cn` 标识；前端不得借用上一次 K 线的来源充当分时来源。公共 research-series 投影把 points 的 time/price/vwap/volume 映射到趋势渲染与数据表／AI 共用的时间、价格、均价及成交量数组；紧凑交易日期转换为实际 ISO 日期。无效／缺失价格、均价或量保留 null，真实零成交量保留 0，不以开盘价或持仓成本伪造昨收。缺少有效昨收或价格时清空价格曲线并分别提示缺基准／无数据；坐标范围按实际价格与均价相对真实昨收的幅度留白，不宣称该范围是证券涨跌停限制。

## 资讯一键 AI 分析（ADR-0046）

资讯列表、资讯详情、持股摘要和首页资讯入口统一调用同一流程，不保留独立的预览实现。点击后由 Fund 读取所选资讯详情／正文、生成当前持仓背景和组合证据，再经既有 Shell Broker 调用全局默认模型；用户不需要选择策略、模型、持仓、资料或任务。

正文优先有效缓存，缺失／过期通过 `POST /api/information/content` 自动获取；抓取失败但有摘要时继续并标记“基于摘要，全文未获取”，只有标题时标记资料不足；无效、已删除或权限错误停止。正文按包含提示词和结构字段的 16000 字符信封有界发送，证据必须带 `basis`、`contentSentChars`、`contentTotalChars`、`contentTruncated` 和 `fullTextRead`，后者只在实际发送完整正文时为 true。

持仓背景由 Fund 后端从权威账本聚合：按证券身份跨账户合并，保留标的、名称、资产类别、可用占比、估值时间和质量；清仓／自选／研究候选不进入，未知和过时不补零。默认证据不包含账户名称／标识、绝对金额、流水或个人备注；比例模式同范围，隐藏模式不得发起。

一次点击最多一次推理；同条重复点击、切换资讯、隐藏、离开、取消及迟到响应不得重复计费或串结果；普通重绘、主题／语言切换和快照更新不自动推理。无全局默认模型时明确报错并保留配置入口，不回退模型列表第一项。结果复用既有结构校验、报告保存、历史与 Tokenusage 单一计费 owner。

金额／比例切换不改变资讯分析的授权范围，不取消或重发推理；切为隐私隐藏仍取消，并明确显示取消原因。自动取得正文后，分析标题区重读条目状态，实际发送覆盖仍以证据包为准。首页“查看全部”继承当前资讯范围。历史目标名称／日期明确标为历史信息，不参与当前金额目标计算。

首页非现金市值按已登记资产范围计算：未登记现金仍显示未知，但不阻断完整的已登记非现金估值；已登记资产估值不完整时仍返回未知。市场时间保留上游市场本地时间，兼容紧凑、横线及斜线日期格式，不用抓取时间补行情时间。资讯原文由 Shell 校验 HTTP(S) 链接后按当前入口打开新标签页；Web 无扩展 API 时使用浏览器窗口能力，失败在详情内明确提示。

资讯列表对同来源、同日、标题与非空摘要完全相同的财经／股票新闻，在范围筛选后、分页前折叠重复展示；不同阅读／收藏状态保持独立，原始条目及关联不删除、不合并写入。公告不套用该新闻折叠规则。
