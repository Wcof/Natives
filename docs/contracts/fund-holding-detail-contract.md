# Fund 私人持仓详情与资讯决定补充契约

## 本地快照与行情刷新

普通首页 `GET /api/home/snapshot` 与持仓 `GET /api/positions/detail` 只读本地账本、
已保存净值及同 Worker 的估值缓存，不同步等待季度穿透。缺数据保持明确缺口。
首页 `refreshEstimates=1`、持仓 `refresh=1` 才刷新公开市场与基金估算；由页面原有
刷新 owner 发起，不新增常驻任务。首次先呈现本地数据，随后补充估值；离页取消请求，
迟到响应不能覆盖新页面。整批外部 I/O 使用 20 秒总时限，不把每个子请求各自的
10 秒超时累加成数分钟。估算缓存按基金、基准净值和当日去重，60 秒内不重复穿透。

状态：2026-10-11 修复实施入口。保持当前 Runtime、安全、账本与主题 owner；不改变产品或进程边界。

## 私人收益历史

`GET /api/holding/income-history` 接受正整数 `accountId`、`fundId`、北京时间日期 `from`、`to`，区间最多 370 天，结束日不晚于当前北京时间。可传 `expectedRevision`；版本变化返回 409，不混合新账本与旧持仓摘要。不存在或已归档账户／标的返回 404。

响应包含 `dataRevision`、`from`、`to`、`rows`、`status`、`missingCount`。每行 `date`、`amount`（元的精确十进制字符串或 null）、`rateBps`、`baselineDate`、`reason`；金额和比率沿用 `IncomeBook` 的历史份额、确认交易、费用与资金流规则，不使用 UI 当前份额。未持有日期不补零；价格／账本覆盖不足明确缺口。

用户于 2026-10-12 明确口径：只显示登记持有后有依据的个人收益，登记之前为空，不回补假记录。真实券商／银行到账没有接入时显示空状态，不阻塞其余整改。AI 沿用 ADR-0037 的统一 Extension broker → Model Host 路由与现有供应商配置，不增加模块直连或模块凭据副本。

## 季度披露比较

优先获取天天基金档案最近两期真实披露，以证券身份对齐净值占比并计算百分点差，不将供应商单个变化字段直接当作比较结果。响应注明本期、上期报告截止日、来源与覆盖范围；上期未出现在披露集合中只标记未披露，不擅自视为零持仓或新建仓。跨年时查询上一年。移动端当前披露可作来源降级及板块补充；不能获取前期时不伪造比较值。

公开价格和私人账本分开：场外优先已保存 NAV，覆盖不足时锁外补充最多 400 条公开历史且本地值优先；场内仅使用未复权价格历史，复用现有市场缓存，锁外取得来源后再校验账本版本。查询不保存估值或产生交易。币种未核实或不支持时明确 unavailable。校准按实际锚点恢复后续数量；跨校准当天不能可靠归因时返回明确原因，不能将校准差额当收益。无法归属到本标的的账户现金事件不擅自分摊。

占比变化只表示披露权重的百分点差，不能推断为基金经理实际增持或减持。档案适配器不填充交易变化类型；UI 明确每类最多 100 项与未披露部分未知。

Frontend `fund-detail` 拥有选中账户／标的、范围、取消与代际；图表 renderer 拥有图表及异步初始化代际。离页、隐藏、隐私、语言／主题改变遵守现有 Surface 事件，迟到结果不能重建离页图表或覆盖新身份。

## 资讯决定（用户已授权 v28 增量实施）

现有 `decision_records` 的 `event_id` 是非空 `watch_events` 外键，动作仅允许 observe／defer／done；因此禁止提交 eventId=0、中文动作或伪造规则事件来记录资讯决定。

v28 仅新增 `information_decisions` 表，不重建旧表：真实 `information_id` 与已保存 `report_id` 外键，动作、用户理由、唯一 requestId、创建时间。报告内已有证据快照、数据版本、模型和资讯内容版本，决定以报告为不可变依据。迁移重复执行、v27 保留数据、外键、失败回滚和重试幂等须验证；只在隔离库运行。

写操作验证 report.task=news_impact、证据确含该资讯、资讯内容版本和报告未删除。用户通过现有 dialog 选择 observe／defer／done 并输入理由；保存操作不会改变事件状态、账户资金或生成交易。历史列表返回两类记录的明确 sourceKind，原规则事件路径保持兼容。

用户于本会话明确授权 v28 新增表与隔离库验证。不得将报告保存或决定记录视为成交；不得在修复验收中操作真实用户库。

决定历史的「查看报告与材料」通过现有 `GET /api/analysis/reports?id=<正整数>` 精确定位已保存报告。默认分页列表保持原响应范围；指定 ID 时追加该报告的不可变 evidence 快照，不依赖当前资讯正文或最新行情重建。非法 ID 返回 400；不存在／默认未包含归档报告时返回空列表。历史查看可显式传 `includeDeleted=1` 并标注归档状态，不触发推理或新交易。报告查看沿用金额隐私限制，隐私切换关闭私人模态。
## 全页面展示修订（2026-10-13）

### 场外持仓编辑重试

新增、期初更正和校准的 `requestId` 对应规范化输入与原结果，回执和账本改动必须同事务提交。丢失响应后相同请求重放原结果，不再修改份额、版本、审计记录或 revision；同一身份更换输入返回冲突。编辑只允许已有活动账户，不得在只读预览或编辑失败时创建账户。复用 `app_meta` 保存非淘汰的业务回执，不新增 schema；版本检查仍对新请求生效。

### 持仓汇总、首页今日收益与基金主题

窄窗下金额摘要按可用空间降为单列，不能将金额和小数部分任意断行，或缩小字号来维持桌面列数。常见金额应完整显示；极长精确数值保留原文并在数值区域内滚动，不能撑破整页或四舍五入伪装完整值。

公开研究的周期栏与绘图栏分别拥有横向滚动，键盘聚焦末端工具不能卷走整块图表。窄窗保留图表正常比例，详情主体可纵向滚动至成交量与研究卡片。调色面板使用浏览器顶层 Popover，保持现有内容与样式，不能被工具栏滚动容器裁掉；Escape、外点和离开研究页关闭面板，焦点合理返回。搜索初次上／下箭头分别选择末项／首项，随后循环；自选与历史入口切换面板内容，重复点击当前入口才关闭。

股票工作台样式由 `ui/src/styles/stock-detail.css` 维护；基金四部分详情由 `ui/src/styles/fund-detail.css` 维护。构建产物与 `ui.rs` 编译期拼接按此顺序加载，随后应用现有投资页覆盖样式，不能只修改 dist 或为规模检查拆成无业务含义的片段。

趋势自选一览复用 `/api/market/quotes`，每批最多 60 个受支持代码；1／5／20 个自选共用一次批量读取，不能逐行发请求。场外基金等该行情源不支持的标的不补零，不假称盘中价格。面板拥有请求及取消代次；关闭、切到历史、离开趋势页和页面隐藏时取消，迟到响应不能覆盖新面板。行操作使用原生按钮，键盘选择与鼠标选择相同。

- 「账户管理与持仓汇总」常驻展示排序、汇总和管理动作，不使用折叠控件；单个持仓详情保持原有展开交互。
- 首页摘要原「待到账」改为「今日收益」：消费与持仓相同的证券日收益汇总，允许负值；有基金估算时使用包含已知正式值的统一估算汇总，明确证券范围、日期、估算和缺失覆盖。线下退出应收仍在其原位置展示，不当作投资收益。没有可计算的持仓收益保持未知，不以持仓市值代替收益。
- 基金卡片和详情展示公开主题标签，含场内基金；只解析天天基金「相关主题基金」中的明确归属，不能把「热门主题基金」推荐标签当作当前基金分类。未提供主题时可显示公开资料中的跟踪指数；仍无数据则显示未提供，失败则显示失败与重试。代码／供应商对应关系、来源和采集时间保留，不从基金名称或股票成分推断标签。
- 主题资料单独有界读取，不阻塞账本初始化；复用模块公网网络防护及请求缓存，页面隐藏／离开取消，隐私模式不展示或请求标的身份，不新增持久化 schema。

### 当日基金更新与穿透估算

进程内行情缓存保存标的身份、价格与上游时间，不保存账本数量作为后续估值权威。偏好、规则及资讯等写入推进 revision 后，同一 Store 的已有标的价格仍可复用；消费时重新读取当前数量、NAV 和资产，按当前 revision 重建估值批次。新增标的缺价仍为未知，旧时间必须保留，不能将缓存价格伪装成刚取得的行情。不同 Store 的行情不得串用。

正式净值仍由既有 NAV 同步进入 `fund_nav`，持仓／首页优先使用已发布的今日确认值。未确认今日净值时，在既有 API 中另提供 `estimate`／`income.estimatedDay`：用最新公开季度股票持仓权重乘以同日场内报价涨幅，计算已披露仓位的贡献及当前份额的参考金额。未披露或缺同日报价的仓位不外推，估算净值仅是“其余仓位不变”的参考情景；必须展示模型、披露日期、行情时间、覆盖率及不完整状态，不得称为真实净值／真实当日收益。

估算不写入 NAV、收益历史、核对快照、现金、成本或交易确认。场内股票／ETF 继续消费真实报价；场外估算在模块锁外获取资料与行情，使用现有有界缓存，版本变化后重新取账本数量。首页与持仓共用同一计算口径，基金详情和卡片可展示当日估算金额／涨幅及参考净值，确认数据发布后优先显示确认值。

共享前端调度继续按配置处理开市行情；净值发布窗口内有未更新基金时，休市检查缩短至 60 秒，其他休市仍为 30 分钟。NAV 读取尝试至少间隔 30 秒并去重，已更新今日净值后停止重复同步；隐藏／离开取消 owner 任务，不新增常驻服务或独立轮询。

本轮仅调整模块 UI 投影，现有 Host／账本／公开行情／统一推理代理仍为 owner，不新增数据表。

- 资讯、决策历史提供独立模块内浏览视图；首页资讯的 AI 决策继续在首页内联更新，不恢复旧独立 AI 跳转。
- 资讯页默认展示全部已采集资讯，all 采集覆盖公共财经、持仓与自选；首页默认仍为持仓相关。公共财经采用东方财富国内经济、国际经济、证券聚焦、产业经济栏目公开列表，固定来源 `em_finance`，无持仓也采集；market 只采集／展示该来源，不发送私人身份。无明确证券身份的财经资讯不建立私人关联。沿用现有来源状态、个人收藏、归档、幂等存储及任务 owner，不新增 schema；单次最多 30 条公共财经、整体 200 条、20 秒，公共财经先采集以免被持仓队列挤掉。栏目合并时按上游文章 ID 去重，重复采集保留个人收藏与归档状态。默认排序在同一天按政策／经济数据主题、市场主题、其他财经与一般公告排列，再按发布时间；公共财经不凭“重磅／独家”等标题措辞提权，这只是明确的主题规则，不是 AI 判断或个人适配评分。标题、摘要、来源和真实时间分层呈现，范围／检索常显，高级筛选折叠，匹配静态原型的资讯阅读布局。进入资讯页先读已保存内容及来源状态；在金额／比例展示模式下，启用来源尚未采集或最近尝试已超过 15 分钟时，发起一次有界采集。相同会话失败尝试同样节流，显式刷新不受此限制。来源禁用及隐藏模式不自动采集；离开／隐藏取消页面拥有的任务。页内提供刷新、取消、下一批及真实结果／失败提示，完成后同时更新资讯页与首页投影，复用现有 refresh/status/cancel API，不生成 AI 或交易。
- 线下资产采用卡片，金额使用整数 minor 的精确格式化；分页汇总明确为本页范围，完整管理资产仍由首页快照提供。
- 股票私有详情采用顶部四卡摘要及概览／记录／资讯／研究栏目；公开图表与绘图能力保留在研究栏目。记录按账户和基金身份查询，保持分页、语言切换时的页码及取消／隐私防护。
- 基金详情保留基础信息常驻及三个图表栏目，增加真实持仓选择器、区间摘要，季度表按名称／最新涨幅／占比／较上期排列。
- 市场发现卡片消费真实板块行情，完整板块表可展开；不会把 Demo 候选或固定技术分数写入生产。
- AI 卡片只分块显示 Host 返回的 `structure_verified` 校验结果；未校验内容显式回退原文。发送预览显示材料摘要，完整结构可主动展开，原有授权与取消流程不变。
- 设置默认展示真实约束摘要、目标配比与金额目标。约束、预留、组合、账户和模型编辑复用各自原入口；未知条件不补造默认投资规则。
- 交易流水默认收整次级列并提供本地检索；导入步骤由实际预览／提交状态驱动，输入变化取消旧预览，提交仍复用稳定幂等身份。



## 2026-10-19 · 趋势分时消费契约

`/api/trends/minute` 与 `/api/market/minute` 共用行情 owner，返回 `symbol/date/source/preClose/points`。来源由后端实际固定请求的 `web.ifzq.gtimg.cn` 标识；前端不得借用上一次 K 线的来源充当分时来源。公共 research-series 投影把 points 的 time/price/vwap/volume 映射到趋势渲染与数据表／AI 共用的时间、价格、均价及成交量数组；紧凑交易日期转换为实际 ISO 日期。无效／缺失价格、均价或量保留 null，真实零成交量保留 0，不以开盘价或持仓成本伪造昨收。缺少有效昨收或价格时清空价格曲线并分别提示缺基准／无数据；坐标范围按实际价格与均价相对真实昨收的幅度留白，不宣称该范围是证券涨跌停限制。

初次加载与轻量刷新复用同一投影与渲染逻辑。刷新独占 AbortController／generation，换标的、切页和隐藏暂停时取消；迟到响应不能改写当前图表。AI 证据使用实际分时日期、公共点与该次来源，不套用上一次 K 线查询身份。
