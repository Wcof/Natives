# ADR-0047：网页连接与业务休眠分离

- 状态：Accepted（2026-10-21，用户明确要求空闲回收后再次使用自动恢复，并修复断线文案）
- 范围：补充 ADR-0042／0045 的网页 document owner；不增加进程、端口或持久凭据。

## 问题

隐藏页释放业务 Surface 和 SSE 后，Core 在无人持有时退出。普通网页没有 Native Messaging 能力，返回旧标签页不能自行启动已经退出的本机程序。断线提示再从该服务请求语言文件，失败时显示内部 key。

## 决定

1. 已授权且尚未关闭的 Web document 是轻量连接 owner，复用每页唯一 SSE。可见时仍按 Surface 过滤任务事件；隐藏时改为无业务 Surface 的已鉴权 SSE，只维持可恢复的 Core 连接，不向隐藏业务分发失效事件，不续租模块、启动查询或保留 iframe／任务。
2. 模块隐藏 60 秒释放、最后业务 owner 释放后 60 秒回收 Worker、shutdown 后 ≤2 秒退出不变。返回可见时重新取得 Surface 并沿已有握手／启动路径恢复模块，不重放写操作。
3. document 的 pagehide 关闭连接与重连 timer；BFCache pageshow 恢复一次。最后实际连接释放后，Core 从释放时起计算原 60 秒宽限；没有页面时不因 Cookie 或缓存会话保持运行。扩展行为与 Service Worker 禁止保活规则不变。
4. 连接仍受 Cookie／Origin、原有 SSE 容量及有界队列约束。注销和显式停止仍撤销授权；Core 崩溃／被用户停止后的普通网页不能凭空获得本机启动权限，仍从受信 Launcher 打开，不引入守护进程或免鉴权唤醒接口。
5. 断线必需文案从现有 zh_CN／en locale 单源生成随页面模块加载的窄投影。语言请求失败或超时也能显示本地化提示；不硬编码第二套手工维护文案，不将资源错误伪装为连接成功。

## 验收

- 隐藏后业务租约／Worker 按原时限回收，保留唯一轻量连接；停留超过原 Core 退出期限后返回可见，自动取得新租约并恢复模块。
- 隐藏不执行业务查询或分发，不重复 SSE；关闭／BFCache、异常与注销清理，其他窗口不受影响；最后连接关闭后 Core 回收。
- 中文／英文语言文件请求失败、超时、缺 key 时连接提示仍可读且无 key；双主题、窄窗和键盘可用。
- 使用隔离数据进行真实 Chrome／Core 验证，记录进程、连接及 Release 短时资源样本；工程门禁通过不替代完整长测或发布验收。
