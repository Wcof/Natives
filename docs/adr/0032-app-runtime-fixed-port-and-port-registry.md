# ADR-0032：App Runtime 固定默认端口与本地服务端口注册表（Fixed Default Port and Local Service Port Registry）

- 状态：已接受（accepted，2026-09-20）
- 决策者：产品方（用户）
- 关联文档：ADR-0031（被本 ADR 部分修订）、ADR-0020、ADR-0029、`docs/standards/technical/02-security.md`

---

## 1. 背景与问题

ADR-0031 规定 App Runtime 的 loopback HTTP 服务器绑定 **127.0.0.1 动态端口**（`TcpListener::bind(("127.0.0.1", 0))`），端口仅通过 Native Messaging `app:start` 响应（`StartResult.port`）告知调用方（Chrome 扩展沙箱页面）。该设计在纯扩展场景下工作正常，但带来两个问题：

1. **进程外消费者无法对接**：不属于 Chrome 扩展会话链路的本地组件（如 macOS 顶栏 `natives-statusbar`、诊断脚本、集成测试 harness）无法在发起 Native Messaging 会话之前得知服务端口，也就无法轮询 `/api/tray/state` 等只读状态接口。硬编码猜测端口（如 8765）在动态端口方案下永远失败。
2. **端口分配无台账**：多个本地 loopback 服务（当前与未来的）各自为政地选端口，无统一登记，容易冲突或与系统服务撞车，且无一处文档可以查证「哪个端口属于哪个服务」。

## 2. 决策

### 2.1 App Runtime 默认绑定固定端口

1. `natives-app-runtime` 的 loopback HTTP 服务器**默认绑定固定端口 8765**（`127.0.0.1:8765`），取代 ADR-0031 的「纯动态端口」默认值。
2. 端口解析优先级（从高到低）：
   - 环境变量 `NATIVES_APP_RUNTIME_PORT`（显式覆盖，值为 `0` 时强制回退动态端口）；
   - 默认固定端口 `8765`；
   - **占用回退**：若默认端口被占用（`bind` 返回 `AddrInUse`），自动回退绑定动态端口（`:0`），并照常通过 `StartResult.port` 上报实际端口。
3. **安全性不放松**：固定端口不改变任何鉴权与边界——业务 API 仍要求沙箱 `Origin: null` + 绑定 generation 的 Bearer Token；固定端口上暴露的只有与动态端口完全相同的接口面。绑定始终限于 `127.0.0.1`，严禁绑定 `0.0.0.0` 或非回环地址。
4. **生命周期不变**：本 ADR 不改变 ADR-0031 的进程模型——运行时仍由 Native Messaging 连接持有（stdin EOF / 页面关闭 ≤2s 退出），固定端口不意味着常驻服务。顶栏等消费者在运行时存活期间轮询固定端口，进程退出后端口自然不可达。
5. 多实例并发（用户同时打开两个内置应用）：后启动的实例回退到动态端口并经 `StartResult` 上报给其页面；固定端口始终服务于「第一个就绪的实例」，供进程外消费者对接。`app-runtime-core` 的单实例运行时锁语义不变。

### 2.2 本地服务端口注册表

1. 建立 `docs/standards/technical/05-port-registry.md` 作为 Natives 全部本地 loopback 服务端口的**唯一登记台账**。任何代码引入、变更或退役一个本地监听端口，必须先在该文档登记/更新。
2. 登记条目必须包含：端口号、服务/二进制名、协议与路径前缀、鉴权方式、生命周期（常驻/会话式）、消费方、注册来源（本 ADR 或后续 ADR）。
3. 端口申请规则：
   - Natives 本地服务使用 **8765–8799** 区间（回环限定），由注册表顺序分配，禁止抢占区间外端口或已知系统端口；
   - 新服务申请端口 = 在注册表追加条目并在 ADR 中说明理由；冲突时由注册表仲裁；
   - 未在注册表登记的监听端口视为违规，代码评审与 `apps:check` 类检查应拒绝。
4. 首批登记：`8765` → `natives-app-runtime` loopback HTTP（本 ADR）。

## 3. 后果

- 正面：顶栏（`natives-statusbar`）、诊断工具、测试 harness 可直接对接 `127.0.0.1:8765` 轮询只读状态，无需自建 Native Messaging 会话；端口台账消除冲突与查证成本。
- 代价与缓解：固定端口存在被第三方进程抢占的可能——回退动态端口保证功能不中断，`StartResult.port` 保证扩展页面路径不受影响；轮询方须容忍端口不可达（进程未运行）为常态。
- 明确不做什么：不引入端口预测/扫描逻辑；不为顶栏放宽 Bearer Token 鉴权（只读对接所需的鉴权豁免若未来需要，另立 ADR）。
