# ADR-0040 · 模块推理流式反馈与有界取消

- 日期：2026-10-14
- 状态：接受（用户要求修复真实投资 AI 分析失败）
- 范围：仅修订 ADR-0037 的整次 30 秒超时语义，不改变 owner、权限、路由、持久化或产品边界。

## 证据与决策

已有商汤模型经统一 Model Host 简单文本约 4 秒成功，结构化公开资讯证据在 30.1 秒被本地总时限取消。不能据此归因为内核 v7 失效。供应商官方 [接口](https://github.com/OpenSenseNova/SenseNova6.8/blob/main/API_CN.md) 支持 SSE、reasoning 与 content 分离。

统一 Host 请求流式输出，任务开始立即返回；状态只回传等待／推理／生成阶段，不回传或存储推理正文。首响应最多等待 60 秒（与供应商官方文本示例一致），首个数据到达后保留 30 秒流无数据保护，整项任务绝对截止 90 秒；模块轮询上限 95 秒。输出仍限制 8000 字符，SSE 传输限制 1 MiB，单行 64 KiB，现有任务数量上限和 owner 隔离不变。不增加自动重试、不静默改模型、不向页面暴露凭据。错误按鉴权、额度、限流、服务不可用、超时、截断区分，不传播上游原始错误体。

供应商忽略 stream 返回普通 JSON 时保留现有解析；错误、取消、EOF 及断连释放网络资源。未收到明确终止或正文时不得报告成功。

内核跨主版本仍需独立 SDK／依赖／补丁迁移，本次不解除此保护；后续 v8 迁移由 [ADR-0041](0041-cliproxyapi-v8-kernel-migration.md) 单独授权并实施。

## 验证边界

使用现有 Go／Extension／UI 门禁和隔离 Native 流程，不修改测试或验证代码。真实供应商仅发送合成公开内容，不发送用户资产。验证失败如实保留，不能将模拟供应商通过视为真实供应商完成。

## 2026-10-19 · 用户授权的生成额度配置

用户明确选择投资生成额度可配置、默认 4096 tokens，并在发送预览中标明。Fund 通过既有版本化财务设置保存 `aiMaxTokens`，不新增 schema；设置范围为 512～8192 的整数。每次预览读取权威设置并冻结本次额度，明确此值包含模型思考与正文，增加额度可能增加 Token 消耗。预览后配置变化时要求重新预览，不静默提高额度。通用 Broker 与 Model Host 分别校验并转发 `maxTokens`；未提供参数的已有调用保持 1600 tokens。90 秒总超时、8000 字符正文、SSE 与 owner 上限均不变，不新增自动重试或绕过结构验证。
