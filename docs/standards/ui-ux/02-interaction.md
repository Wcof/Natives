# UI/UX 02 · 交互与状态反馈

> 版本：4.0.0 · 日期：2026-09-14

#### R-U9 · 反馈渠道按作用域选择

- **等级**：MUST
- 短暂操作结果使用 toast；当前组件状态使用 inline；需要决策使用 `<dialog>`；需长期回顾才进入持久记录。
- 禁止 `alert`、`prompt`、`confirm`。
- 错误反馈包含发生了什么、数据是否保留、用户下一步。
- 控件在前置条件未满足时（例如未选择目录的「新建」「导入」）必须禁用并说明原因，或直接隐藏；不得保持可点但静默无响应——静默 return 会被读成"按钮坏了"，并让视觉权重花在一个走不通的动作上。

#### R-U10 · 加载、空、错误、不可用分离

- **等级**：MUST
- loading 不显示假数据；empty 说明为何为空；error 保留仍可信的旧数据并提供重试；unsupported 解释边界。
- 状态区占用稳定空间，刷新不造成卡片大幅跳动。

#### R-U11 · 危险操作明确

- **等级**：MUST
- 清除数据、删除 Workspace、覆盖冲突文件等不可逆操作使用明确对象、范围和后果的确认。
- 隐藏、停止、关闭、更新产品不等于删除数据。
- 默认按钮不能落在不可逆动作；键盘 Escape 安全取消。

#### R-U12 · 全局导航和快捷键统一

- **等级**：MUST
- 全局跳转/搜索使用现有统一入口；快捷键判断 `metaKey || ctrlKey`。
- 不劫持浏览器保留快捷键；页面注册一次并在销毁时移除。
- 激活入口必须有可见选中状态、文本/tooltip 和键盘路径。
- **可点击的表格行必须键盘可达**：行加 `tabindex="0"`，`Enter`/`Space` 与点击等价（复用同一个 handler，不另写选中分支），选中态同步 `aria-current="true"`（表格语义下 `aria-selected` 只对 `grid`/`row` 合法）。焦点环用 inset `outline`，避免被滚动容器裁掉；行内按钮/复选框的按键要在行 handler 里放行（`e.target !== tr` 直接 return）。参考实现见 ADR-0049 D11。

#### R-U13 · Structured 与 Free 都是有界布局

- **等级**：MUST
- Structured 使用固定栅格、可预测碰撞和响应式断点；Free 使用有限工作区、缩放上下限和确定初始视口。
- 不实现无限画布、协同编辑、连接器或运行时插件。
- 创建、移动、缩放、分组和层级操作不得把组件移到不可恢复区域。

#### R-U14 · 手势遵循 draft → commit/rollback

- **等级**：MUST
- drag/resize/pan/zoom 的 pointer move 只更新 draft；pointer up/stop 一次提交。
- Escape/pointercancel/写入失败恢复最后确认快照。
- Header 非控件空白区可拖拽；Body、button、input、link、图表和滚动区是取消区域。
- 方向键提供移动替代，焦点和选中状态可见。

#### R-U15 · Space 数据操作不破坏布局

- **等级**：MUST
- 同步、刷新、切换时间范围和筛选不得改变 Widget 坐标、尺寸、选择或滚动位置。
- 多 Widget 相同 adapter key 只产生一次查询。
- 时间范围使用真实 Host 支持的区间和本地时区；不提供伪自定义范围。

#### R-U16 · App Center 使用模块语义

- **等级**：MUST
- 每个内置模块始终有可找到的卡片；隐藏只影响导航入口，Apps 页面仍可管理。
- 主要动作只有打开/重新打开；辅助动作是显示/隐藏、偏好、数据管理和诊断。
- 不显示安装、下载、更新模块、卸载模块、启动服务、停止服务等旧语义。
- 模块异常显示修复 Natives、重新打开或数据恢复等真实动作。

#### R-U17 · Launcher 引导可取消且可重入

- **等级**：MUST
- 首次启动打开 Chrome 扩展管理页、随包扩展目录和本地 HTML 指南。
- 指南说明“开发者模式 → 加载已解压的扩展程序 → 选择包含 manifest.json 的目录”。
- 用户可关闭/稍后继续；再次启动从实际检测状态继续，不重复假完成。
- 扩展握手成功后直接进入 Natives；Launcher 随后退出。

## 合规自检

- [ ] 反馈渠道、状态和危险操作语义正确。
- [ ] 布局手势可回滚且不在 move 写库。
- [ ] 数据刷新不破坏布局。
- [ ] 内置模块可找到且无独立安装语义。
- [ ] 首次扩展引导真实、可取消、可恢复。
