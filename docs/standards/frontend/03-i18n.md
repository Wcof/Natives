# 前端 03 · Chrome Extension 国际化

> 版本：4.0.0 · 日期：2026-09-14
> 唯一文案源：`extension/_locales/zh_CN/messages.json`、`extension/_locales/en/messages.json`

#### R-I1 · 用户可见文案走 Chrome i18n

- **等级**：MUST
- 按钮、标签、占位、toast、空态、错误、title、aria-label 和引导文案使用 `chrome.i18n.getMessage` 或页面统一 `t()`。
- HTML 使用现有 `data-i18n` 装配。
- 品牌名、协议标识、纯数字和用户数据可以直接显示。

#### R-I2 · 中英文 key 完全一致

- **等级**：MUST
- 新增、删除、重命名 key 同时修改 zh_CN/en；key 集合必须完全一致。
- 英文不得复制中文、留 TODO 或空字符串。
- 删除旧功能时同步删除两套 locale 的孤儿 key。

#### R-I3 · key 使用稳定语义

- **等级**：SHOULD
- key 描述用途，不把完整中文句子当 key；同一语义复用已有 key。
- 不因小范围文案调整改 key；语义改变才改名。

#### R-I4 · 动态值安全插值

- **等级**：MUST
- 用户数据、路径、金额和模型名通过 DOM `textContent` 或 Chrome placeholders 插入。
- 禁止用未转义字符串拼 `innerHTML`；允许的静态模板继续经过现有 sanitizer。

#### R-I5 · 语言切换即时

- **等级**：MUST
- 页面语言改变后刷新当前可见投影，不重置 Workspace、筛选、布局或业务状态。
- 日期、数字、Token 和货币按当前 locale 与明确时区/币种格式化。

#### R-I6 · 安装与模块文案使用当前产品语义

- **等级**：MUST
- 只说“安装/更新 Natives”；内置模块使用“打开、显示、隐藏、初始化、修复数据”。
- 禁止出现“安装基金、下载模块、模块更新、应用商店 Catalog”等旧产品文案。

## 合规自检

- [ ] zh_CN/en key 一致且值完整。
- [ ] 所有 UI/ARIA/错误文案已本地化。
- [ ] 动态内容安全插值。
- [ ] 切换语言不改变业务状态。
- [ ] 内置模块没有独立安装文案。
