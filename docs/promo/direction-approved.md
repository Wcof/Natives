# direction-approved.md

## 记录

用户原话（2026-10-25，本次会话）：

> 「装好后给当前这个项目做一个宣传片，做成 60 秒或120秒 的动画，**一切都由你来决定，你不用再询问我**。一直跑出你觉得完美没问题的之后导出 MP4 和 GIF」

## 判定

- 三方向门（`references/directions.md`）在本次会话被用户**明确豁免**：用户要求不询问、由我决定。
- 豁免依据：SKILL.md §3「唯一豁免（都要在 direction-approved.md 记原话或理由）：用户本次会话明说跳过」。
- 我仍执行了三方向的**探索工序**（六个候选 → 收窄到三个 → 选一个），只是不把选择权交回用户；过程记录在 `导演稿.md` §2。

## 时长选择

- 用户给的是 60s 或 120s，我选 **60s**。
- 理由：这是一支产品宣传片（不是功能演示长片），60s 足以完成「提出问题 → 给出机关 → 展开形态 → 落品牌」四拍；120s 会把信息密度摊薄，且 GIF 体积不可接受。

## 方向选择

选定方向：**「蓝图 / 图纸」**（Blueprint），详见 `导演稿.md`。

一句话：把产品当成一栋**建在你机器里的房子**来拍——纸与墨的丈量、门的开凿、四个房间、最后收成一张门牌。
