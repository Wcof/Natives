# 助理布局与会话修复设计

## 目标

将助理收敛为类似 Codex 的项目-会话工作区，并修复现有会话 RPC 契约不一致导致的空列表和不可用状态。

## 布局

- 左侧全局 Sidebar：`助理` 与 `快速访问` 同级。助理标题只提供“折叠/展开”和“新增项目”两个图标操作；不提供全局新建会话。
- 助理项目：作为二级节点，视觉层级与个人主页、桌面一致。点击项目切换当前项目并展开/折叠会话；项目行右侧提供“新建会话”。
- 会话工作区：左侧为项目/会话导航，中间为会话内容和输入框，右侧为当前会话信息（Provider、模型、运行状态、用量、文件变更和产物）。左右栏顶部均提供折叠/展开图标。

## 行为

- 一个会话只有一种创建入口：项目下的“新建会话”。未选择项目时不显示全局创建入口。
- 助理服务直接由 Tauri command 提供。前端读取会话列表必须使用后端实际返回的数据形状；Provider 读取使用现有 Provider API，而不是未实现的 assistant RPC 路由。
- 保留现有项目、会话、运行检查器和消息输入组件；仅删除过时的 Chat/Agent 参数与重复入口。

## 验收

1. 助理标题只含折叠和新增项目操作。
2. 项目行可展开会话并可新建会话。
3. 助理会话列表、选择、创建能实际调用已注册的 Tauri command。
4. 内容区、输入区和右侧信息栏均可见；两侧栏均可折叠。
5. TypeScript、前端测试、Rust check 通过；新增测试覆盖 RPC 返回形状和导航创建入口。
