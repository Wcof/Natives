# 助理 Codex 式布局与完整会话交互设计

## 目标

将“助理”重构为应用主左栏中的一级目录，并将项目、会话、输入、运行状态和结构化消息统一成一套可真实执行、持久化、恢复的 Codex 式工作区。

## 已确认的界面结构

1. 主左栏只保留一份项目树，不在助理工作区内部渲染第二个左栏。
2. “助理”与“快速访问”是同级一级标题，使用相同的灰色、小号、弱强调样式。
3. “助理”标题只提供目录展开/折叠和新增项目两个图标。
4. 项目为二级条目，项目下的会话为三级条目；项目行提供自身展开/折叠和新增会话。
5. 主左栏的整体折叠按钮位于左栏顶部。左栏关闭后，仅在工作区标题栏显示恢复按钮，避免无法展开。
6. 助理工作区保留中间会话区和右侧运行详情栏；右栏可折叠，但不再出现工作区内部左栏。

## 输入框

输入框是最大宽度约 820px 的底部悬浮式 Composer，默认文本区约 100px，可随内容向上增长。去除贯穿全宽的外层顶部边框。

- 左下“添加”：打开附件菜单，支持系统文件选择。选择结果显示为可移除的附件 Chip；发送时与文本一并持久化为 `file_reference` 消息块。
- 左下“授权”：提供 `readonly`、`ask`、`full_access` 三种会话权限模式。选择后写回当前会话；创建 run 时复制到 `assistant_runs.permission_profile`。
- 右下“供应商 · 模型”：只显示已配置有效 Key 的供应商/模型组合；选择后调用 `conversation.update_model`，后续 run 使用相同组合。
- 右下发送：空输入且无附件时禁用；可发送时为上箭头；执行中变为停止按钮并调用现有取消链路；发送失败时保留草稿和附件。

## 会话消息

- 用户问题靠右、使用浅色圆角气泡；助理回答靠左、无厚重外框。
- 不显示重复头像。消息最大宽度保持可读，长用户消息支持展开/收起。
- 助理消息支持现有结构化块：文本、reasoning、图片、文件引用、工具调用/结果、引用、错误和旧格式兜底。
- 消息悬停显示时间、复制、token；失败或被中断的最后一次回答提供重试。
- 新消息和流式增量到达时，在用户仍接近底部时自动跟随；用户向上阅读时不抢夺滚动位置，并提供返回底部按钮。

## 思考、工具和运行状态

真实 reasoning 块在流式阶段自动展开，结束后自动收起并显示“思考了 N 秒”。持续时间来自 reasoning/run 事件时间戳；没有真实 reasoning 时仅显示“生成中/回复中/组织回复中”等等待文案，不伪称模型正在深度思考。

工具调用按调用 ID 配对，显示运行、成功、失败或拒绝状态；条目可展开查看参数、输出和耗时。权限请求在消息流内展示批准/拒绝按钮，调用现有 `permission.respond`。流式状态栏显示当前阶段和秒级运行时间；执行超过合理时间仍允许用户停止。

## 前后端数据流

1. 选择项目或会话从主左栏触发 `AssistantWorkspaceContext` 动作。
2. 输入框读取当前会话的 provider、model、permission profile。
3. 发送调用 `run.start`，后端在一个事务内写入用户文本块、附件块和 run 快照。
4. 前端调用现有 `assistant.streamChat`；运行事件更新流式内容、reasoning、工具状态、权限请求和使用量。
5. 完成时持久化助理消息的结构化块并调用 `run.finish`；重新打开会话时通过消息与 run 事件恢复同一状态。

## 错误处理

- 无供应商、无模型、无有效 Key 时禁用发送并给出明确配置提示。
- 文件不存在、无法读取或超出合理大小时不启动 run，并保留输入内容。
- `run.start`、流式请求或持久化失败时显示后端错误原文的用户友好分类，不显示笼统的 unexpected error。
- 权限更新和模型更新失败时回滚前端选择。

## 实现边界

复用现有 `AssistantSidebarSection`、`AssistantWorkspaceContext`、结构化消息块、run 事件 reducer、供应商 API 和流式代理。参考 CodePilot 的交互规则，但不复制其组件体系或引入新依赖。本次不实现消息分支、会话 rewind、生成式 Widget 或虚拟列表；当前会话规模不需要这些能力。

助理不保留独立搜索框。后续复用文件搜索的同一入口，并通过搜索类型区分“文件”“项目”和“会话”。

## 验收标准

- 页面上只出现一个项目/会话左栏。
- “助理”一级标题与“快速访问”视觉层级一致。
- 左栏整体折叠、目录折叠、项目折叠互不混淆且可恢复。
- 文本、附件、授权、供应商/模型、发送和停止均有真实后端动作。
- 用户消息在右、助理消息在左；reasoning、工具、权限、错误、计时、复制、重试和 token 状态可用。
- 刷新或重开会话后模型、权限、消息块和最近 run 状态可恢复。
- TypeScript、前端测试、Rust 定向测试、Rust workspace check 和生产构建通过。
