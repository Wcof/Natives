> **文档状态**: 草案 (Draft)  
> **版本**: 1.0.0  
> **日期**: 2026-06-22  
> **适用范围**: Natives 助理功能 (Assistant)

---

## 1. 业务背景与功能定位

Natives 定位为 AI 时代的个人桌面应用容器（"AI Steam Base"），用户可以在其中自由浏览、安装和运行各种页面级 SPA 插件（Modules）。

**《助理》** 是 Natives 的基座级 AI 工作台，位于侧边栏**一级菜单**（与模块管理、创意工坊平级）。它不同于运行在沙箱 Iframe 中的普通插件，而是**直接运行在基座的 Next.js 宿主渲染层**。助理拥有完全的本地特权（通过 Rust 底座代理直接读写本地文件系统、执行 AST 分析、控制终端），承担着 **“指令+自然语言”生成与管理本地插件** 的核心任务。

助理的设计理念沿用 CodePilot 方案，为用户提供一个重型、沉浸式的 AI 对话与代码协作环境。

## 2. 用户故事与核心场景 (User Stories)

### US-1: 侧边栏一级入口沉浸式工作区 (P0)
* **场景描述**: 作为开发者，我希望从左侧菜单栏一键进入《助理》面板，将中间内容区切换成标准的对话框，以便专注于与 AI 进行代码和环境协作，且切换时不会影响底座布局。
* **验收点**: 
  - 点击左侧“助理”图标，中间主内容区渲染为助理工作台。
  - 左侧边栏宽度、底栏终端折叠状态保持不变。

### US-2: 项目级会话隔离与全局草稿箱 (P0)
* **场景描述**: 作为多项目管理者，我希望助理的聊天历史自动与我当前打开的项目目录（Project Folder）绑定。当无项目打开时，它应退避为“全局草稿”，且明确告知我部分高级功能（如项目级 AST 提取）不可用。
* **验收点**:
  - 打开项目 A，助理显示项目 A 下的历史会话；切换到项目 B，会话列表自动更新为项目 B 的历史。
  - 未打开任何项目时，助理提示：“当前无项目上下文，部分能力受限（如 `/create-app` 等指令暂不可用）”，引导用户打开项目。

### US-3: 斜杠指令浮窗与自动补全 (P0)
* **场景描述**: 作为效率用户，我希望在输入框键入 `/` 时能快速弹出一个命令提示框，列出所有可用系统指令（`/create-app` 等）和发现的 Skill/MCP 工具，支持快速模糊检索与按 Enter 键补全。
* **验收点**:
  - 输入框输入 `/` 时，上方弹出浮动框（Popover），按分类（系统指令、Skill、MCP 工具）展示选项。
  - 支持键盘上下方向键选择及回车确认，或鼠标点击选择。

### US-4: 三态气泡可视化 Tool Call (P1)
* **场景描述**: 当助理自动执行写盘、运行命令等副作用工具时，我希望在消息流中看到直观、透明的执行进度 and 结果展示，而不是干巴巴的控制台日志。
* **验收点**:
  - **执行中 (Pending)**: 气泡展示工具名称、参数摘要，带有骨架屏（Skeleton Loading）或旋转 Loading。
  - **成功 (Result)**: 绿色标识，允许点击折叠/展开原始的 JSON 响应。写盘类工具额外展示写入路径与 Kernel 回填的 `contract_id`。
  - **失败 (Error)**: 红色标识，展示报错简要摘要并提供“重试”按钮。

### US-5: 插件安全覆盖与实例物理销毁 (P0)
* **场景描述**: 当我命令助理修改或重新生成一个正在运行的模块时，我不希望旧的 Iframe 进程残留在后台导致内存泄漏或握手冲突。
* **验收点**:
  - 覆盖已存在的模块时，基座拦截并弹窗二次确认：“检测到该应用正在运行，是否强制关闭并应用新版本？”。
  - 用户确认后，前端 `IframeManager` 物理卸载（Unmount）该 Iframe 节点，清除所有事件监听与挂起引用，然后再写入新代码并重载。

### US-6: 静默热更新、变更 Diff 与一键回滚 (P1)
* **场景描述**: 当我修改模块时，如果是仅微调 CSS/HTML 等非破坏性修改，我希望页面静默热更新而无需手动弹窗确认；但同时希望在聊天气泡中看到直观的 Diff 对比，并能一键退回到上一个版本。
* **验收点**:
  - 非破坏性修改（不改 `contract_id`、不升级 Schema、不扩张权限）静默覆盖。
  - 对话消息中展示 Diff 视图（展示修改前后的行变动），并附带“回滚到上一版本”按钮。

## 3. 功能详细描述

### 3.1 界面布局与三皮肤适配 (P0)
* 助理工作台组件树：
  - `SessionList`: 会话列表（支持重命名、删除、绑定项目）。
  - `MessageList`: 历史消息流，支持 Markdown 渲染。
  - `MessageInput`: 多功能输入框，左下角为模型选择器，右下角为发送与停止生成按钮。
* **适配要求**: 自动集成宿主底座的 `Terminal Volt` (暗色)、`Warm Archive` (暖色) 和 `Editorial Index` (编辑风格) 三套主题，圆角、字体、液态玻璃模糊效果与系统一致。

### 3.2 供应商与模型配置管理 (P0)
* **配置入口**: 在宿主已有的设置页（Settings）中增设“AI 供应商”子页面。
* **功能描述**:
  - 支持云端（Anthropic、OpenAI）与本地（Ollama）Provider 增删改查。
  - 提供“测试连接”按钮。测试逻辑必须在 Rust 后端代理执行，前端只接收脱敏后的成功/失败状态，不可持有 API Key 发送网络测试。

### 3.3 逐 Token 流式渲染与 Abort 中止 (P0)
* **流式通道**: Rust 底座代理 SSE 流，合批打包后通过 `assistant:stream_update` 事件将 delta 下行到前端（节流间隔为 16ms，防卡顿）。
* **停止生成**: 点击输入框的“停止”按钮，前端发送 `cancel_stream(session_id)` 到 Rust。Rust 必须立即调用 tokio 任务的 `abort()` 句柄终止连接，并把当前生成结果写入 `assistant.db`，标记为 `interrupted` 状态。

### 3.4 构建错误自愈与熔断机制 (P1)
* **自愈机制**: 当 AI 自动生成代码触发 Linter 错误或 Schema 校验失败时，助理不会直接报错中断，而是将错误结构化回传给大模型，让大模型自动尝试纠错（自愈）。
* **熔断机制**: 自愈尝试最多 3 次。第 4 次失败时必须熔断，在消息气泡中展开完整错误日志，并将控制权交还用户，提供“手动修改”或“放弃”选项，防止 Token 无限循环消耗。

## 4. 非功能性与安全要求 (红线)

### 4.1 🔴 无假数据红线 (MUST)
* 助理界面展示的任何指标（如 Token 消耗量、连接延迟、耗时）**必须来源于真实数据**。
* 在数据未加载完成时，展示 Skeleton 骨架屏或统一的 Loading 状态，**绝对禁止**使用 Mock 占位数值或随机数。

### 4.2 🔴 安全沙箱与 CSP 限制 (MUST)
* AI 生成的 SPA 代码在写入磁盘（`~/.natives/modules/`）前，必须通过 `Contract Linter` 进行静态代码审计（KI-3）。
* 严禁模块包含远程 CDN 脚本，CSP 指令只允许 `script-src 'self' tauri://assets`。
* 任何数据库迁移文件必须是声明式的 JSON Mapping DSL，禁止可执行脚本。

### 4.3 物理隔离的 Assistant 数据库 (MUST)
* 助理所有的会话、消息持久化数据保存在独立的 SQLite 数据库文件 `~/.natives/assistant.db` 中。
* 读写使用独立的连接池，与核心底座数据库 `natives.db` 彻底隔离，防止高频聊天读写造成 WAL 写锁竞争而影响宿主生命周期和模块事务。

### 4.4 KEK-DEK 凭证信封加密 (MUST)
* API Key 的密文加密存储于 SQLite 中，加密密钥 DEK 使用存储于操作系统安全凭据管理器（Mac Keychain / Windows Credential Manager）中的 KEK 进行二次加密。
* KEK 常驻 Rust 内存，绝不暴露给前端进程。

## 6. 验收标准

| 序号 | 验收场景 | 预期结果 |
|---|---|---|
| 1 | 开启无项目会话，输入框输入 `/create-app` | 指令提示框不予展示或置灰提示无上下文，引导用户打开项目。 |
| 2 | 输入 `/` 并键入 `cre` | 自动匹配并高亮显示 `/create-app` 及其参数格式。 |
| 3 | AI 正在输出时点击停止按钮 | 输出立即中断，UI 变为可编辑状态，消息落盘状态为 interrupted。 |
| 4 | AI 生成带有 `<script src="https://cdn.jsdelivr.net...">` 的应用 | 写入时被 Contract Linter 拦截，生成被阻止，触发自愈。 |
| 5 | AI 自愈 3 次失败 | 第 4 次时熔断，气泡变红，折叠显示 Linter 异常堆栈，提供手动操作。 |
| 6 | 覆盖运行中的模块 | 弹出 ConfirmOverwriteModal，点击“确认”后 iframe 物理卸载，旧进程杀死，再载入新版本。 |
| 7 | 运行中切入切出助理页面 | 正在运行的模块挂起进入温层，切回时无缝显示，无重载或状态丢失现象。 |
