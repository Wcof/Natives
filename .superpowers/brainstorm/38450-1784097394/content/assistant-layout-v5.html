必须完整联动的状态

会话呈现

  • 用户问题靠右、浅色气泡；助理回答靠左、无厚重外框
  • Markdown、代码、图片、附件、引用与错误块正常渲染
  • 消息悬停显示复制、时间、token；失败回复支持重试
  • 长消息可展开/收起，新增内容时可靠跟随底部

运行过程

  • 等待首 token 显示阶段文案与秒级计时
  • 真实 reasoning 流式自动展开；完成显示“思考了 N 秒”并收起
  • 工具调用按运行/成功/失败分组，可展开参数和输出
  • 权限请求在消息流内批准/拒绝；执行中发送按钮变停止

后端一致性

思考时间来自 run/reasoning 事件时间戳；工具状态来自持久化 run 事件；token 来自完成事件；重试重新创建 run；权限响应调用现有 permission.respond。UI 不自行伪造状态。
