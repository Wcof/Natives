## 判定依据（worktree vs 独立 clone）
- 独立 clone 的 .git 是「目录」，各自持有完整 objects/refs。
- git worktree 的 .git 是「文件」，内容为 `gitdir: <主仓库>/.git/worktrees/<name>`，共享同一 object store。
